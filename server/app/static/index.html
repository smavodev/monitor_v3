Restricción por red WiFi
Activar restricción por red WiFi OFF
Cuando está activado, las reglas de bloqueo (categorías, sitios y horario) solo se aplican mientras el equipo esté conectado a una de las redes WiFi que definas abajo. Fuera de esas redes — otra red WiFi, cable, etc. — el bloqueo se desactiva automáticamente. Con el toggle desactivado, el sistema funciona como hasta ahora (sin importar la red).
Cada cuánto cada equipo pregunta si debe bloquear o no. Más bajo reacciona más rápido a una excepción o cambio de red; más alto genera menos tráfico contra el servidor (recomendado con muchos equipos).
